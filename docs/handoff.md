## スレの引っ越し（10/27 オーナー「スレが長くなったら新しいスレに移動、動作が遅くなる」）
- オーナーと話すスレは1つだけ（基本スレ）。古いスレは移った後に閉じる。
- いつ移るか：基本スレを作って3日たった夜、またはオーナーへの返事が80通を超えた夜。夜の見回り（23:23）が確かめる。
- 移り方：
  1. 古いスレの燈が、まとめ役に「基本スレが長くなったので『燈からの提案(M/D〜)』を作って」と頼む（message_coordinator）。待っている約束（予約した確かめ）も書く。
  2. 新しいスレの燈が、メモリと handoff を読み、古いスレの朝・夜の見回りと1回きりの確かめを get_trigger で読み、同じ時刻・同じ文で新スレに作り直す（見回りは create_trigger、1回きりは send_later）。古い方は enabled=false。
  3. メモリと handoff の基本スレの名前・予約タスクの番号を書き換える。
  4. 新スレで「こちらに移りました」と待っている約束を1〜2行。古いスレの燈がスレを閉じる。
- オーナーには何も頼まない。
