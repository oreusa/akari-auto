# HPの紹介リール（週1本・11/2〜）

11/2 オーナー：「29秒のリールで、HPの本物の画面を順番に見せる（トップ→おでかけ→泊まり→イルミ→ふるさと納税など）。最後は『プロフィールのリンクから』。曲はいつもの音源、明るい背景、燈の金色」「1本目は今週中。2本目からは毎週1つの機能を大きく見せる。画面は毎週撮り直し、同じ動画はくり返さない」「夕方の枠と入れ替えて出し、入れ替えたおでかけは翌週に回す」。

## 流れ
| いつ | なに | だれ |
|---|---|---|
| 前の日の夜（夜の回） | reel-hp/D.json を保存。その日の reel/D.json（07:30 おでかけリール）は作らず、そのおでかけ先は翌週に回す | 燈 |
| 保存したすぐ後 | hp-reel.yml がその時の本物のHPを撮って約29秒の動画にし、reel-hp/out/D.json に URL | 機械 |
| D の 18:00 | インスタのリール（book.py の book_hp_reel） | 機械 |

- 1本目：11/4（水）18:00「HP全体をひと回り」（トップ→おでかけ→泊まり→イルミ→ふるさと納税）。
- 2本目から毎週1本（水曜 18:00）。毎週1つの機能を大きく見せる：/ima（いまから行ける）→ /tomari → /nesage → /furusato → /illumination → 地図 … の順。同じ組み合わせ・同じ文はくり返さない（下の記録を見る）。
- 見た目：背景 #FFFFFF、線と小さい字は燈の金 #A8783A、字は Shippori Mincho（題）と Zen Kaku Gothic（説明）。ベージュ・アイボリーは使わない。
- 画面は毎回その時に撮る（tools/hp_reel/make.py。先に /?me=on を開いてHPの数えに入れない）。

## reel-hp/D.json の形
```json
{"date": "D", "time": "18:00", "theme": "その週に大きく見せる機能",
 "scenes": [{"url": "/ima", "title": "画面の上の題（短く）", "note": "下の1行（そのページに今出ている事だけ）", "click": "押すボタンのCSS（なくてよい）"}],
 "end_note": "最後の画面の小さい1行",
 "caption": "説明文（URLなし・宣伝の言葉なし・HPの名前は決まるまで書かない）",
 "ig_tags": ["#関東おでかけ", "..."]}
```
- scenes は3〜6つ。題と1行は、書く前にそのページを開いて本当に出ている言葉で書く。
- 作り直し：hp-reel.yml を workflow_dispatch（date=D）。確かめる静止画は `python3 tools/hp_reel/make.py reel-hp/D.json /tmp/x.mp4 1,6,12,18,24,27`。
