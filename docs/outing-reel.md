## おでかけリールの型（2026-11-24〜・関西関東とも）

---
関西（usagi）も関東（akari）も毎日この型で作る。作り方の部品：usagi tools/outing_reel/ai-art/par/（par3.html・pv3.cjs）と hf/jingoji-1124k・hf/gaien-1124k の build-3d.py。
**型（1分3秒・表紙から開く本・VOICEVOX20・人を描かない）**
1. 台本の順（声9文）：①見せ場＋今行く理由（見頃・期間）②そこでできる楽しいこと（体験・食・夜の催し）③驚きの一言（歴史・仕かけ・国宝など）④道中2〜3カット ⑤ひと休み・しあわせな一言 ⑥山場（一番きれいな景色）＋「会いに来て」 ⑦⑧案内（時間・料金・行き方）⑨プロフィールのリンク。声は景色の説明でなく気持ち・楽しさから。
2. 事実は出どころを facts に入れた物だけ（ページの言い回しを q に）。「〜ともいわれる」は断定しない。
3. 絵：Cloudflare 画像AI（akari tools/ai-art/req-*.json）で場面ごとに描き下ろし。1場面2〜3カット・1本12枚前後。本物と違う建物（丸屋根・塔）が写ったら描き直し。
4. 動き（usagi tools/outing_reel/ai-art/par/）：前へ一定の速さ＋横にゆっくり流す・回さない・2〜3秒で切り替え・葉だけ風で揺れる・光の筋ともや・色を締める。xfade zoomin は使わない。
5. 字：札なし・下に大きく明朝・下だけ暗く。案内ページの後ろはぼかした進む映像。光の粒・落ちる葉は出さない。
6. 長さが 63秒を超えたら声を atempo 1.08 まで。超えるなら文を削る。
7. 書き出したら24コマの一覧＋大きい3コマで見直してから本番へ（owner「間に合いそうならそのまま出していい」）。
