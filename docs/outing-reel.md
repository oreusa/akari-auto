# 関東のおでかけリール（10/30〜）

10/29 オーナー：「燈のインスタにも月と同じおでかけ動画をつくる」「同じおでかけ先で漫画も作らせる」「リールは毎日2本。月の関西おでかけリールの関東の版の後に、同じおでかけ先で4コマリール」「音楽は燈が今使ってるフリー音源。どちらのリールもそれでいい」。

## 1日の流れ

| 時刻 | インスタ | だれが |
|---|---|---|
| 毎晩（燈の夜の回） | koma4/D.json と同じおでかけ先で reel/D.json を保存 | 燈 |
| 保存したすぐ後 | outing-reel.yml が動画（約29秒・曲つき）を作り、Cloudflare に置いて reel/out/D.json に URL | 機械 |
| 07:30 | ① 関東のおでかけリール | book.py |
| 08:00 | ② 同じおでかけ先の4コマリール（今のまま） | book.py |

- 曲：bgm/reel_bgm.m4a（オーナーのフリー音源。4コマリールと同じ）。終わり2秒で小さくなる。
- 見た目：月の関西おでかけリール（10/28 型）と同じ動き。燈の色は金（#A8783A）、燈のロゴ、関東の地図（7都県）、リストの画面は燈のHP（都県のボタンを押した所）。
- 表紙の上の2行とキャプションの1行目は、毎回同じ「街の調査で見つけた、関東おでかけリスト」（表紙は小さい行「街の調査で見つけた」／太い行「関東おでかけリスト」。機械が入れる。10/29 オーナー決定。「代わりに調べた」は使わない）。

## reel/D.json の形

```json
{"date": "D", "time": "07:30", "tab": "群馬", "lat": 36.4277, "lon": 139.1424,
 "text": {
  "corner": "GUNMA ─ MAEBASHI",
  "title": ["夜のお花畑に、", "10万輪の光。"],
  "place": "ぐんまフラワーパーク｜前橋市",
  "map_tag": ["MAEBASHI ─ GUNMA", "ぐんまフラワーパーク", "前橋市柏倉町"],
  "map_caption": "赤城山のふもとの花の公園。",
  "date": ["10.29", "THU", "11.23", "MON"],
  "date_title": "Night Bloom", "date_title_size": 58, "date_note": "期間中は無休",
  "point_kicker": "NIGHT", "point_title": "夜の花 約10万輪",
  "points": ["見どころ1", "見どころ2", "17:00〜20:30"],
  "info": [["おとな", "1,200円"], ["小中学生", "400円"], ["時間", "17:00〜20:30"], ["入場", "20:00まで"]],
  "info_note": "JR前橋駅からバスで約30分",
  "list_caption": "群馬のおでかけも。"},
 "caption": "キャプション全文（下の形）",
 "ig_tags": ["#関東おでかけ", "#群馬おでかけ", "#ぐんまフラワーパーク"]}
```

- tab：東京・神奈川・埼玉・千葉・茨城・栃木・群馬 のどれか（HPのしぼりこみのボタンと同じ字）。
- lat/lon：施設の場所（公式ページの住所から。地図のピンの位置になる）。
- title は2行、各8字くらいまで。points は3つ（3つ目は時間など短い物）。info はちょうど4行。date は始まりと終わり（1日だけなら同じ日を2回。曜日は英語3字）。
- 中身は全部、4コマと同じ公式ページで確かめた事実だけ（ミス帳・preflight の照らし合わせに「おでかけリール」の行を足す）。

## キャプションの形（月と同じ・1行に1つ）

```
（1行目は機械が入れる）
夜のお花畑に、10万輪の光
10/29(木)〜11/23(月・祝)
ぐんまフラワーパーク（前橋市）
「Night Bloom」
17:00〜20:30（入場は20:00まで）
おとな 1,200円
小中学生 400円
JR前橋駅からバスで約30分
✧ 内容は変わることがあります。出かける前に公式ページで確かめてください。
保存して、週末のおでかけに。
```

- URL は書かない（インスタは押せない）。「プロフィールのリンク」の1行とタグは機械が足す。
- ※ は使わない（10/29 オーナー「※嫌だな」）。

## 作り方（手で確かめるとき）

```
python3 scripts/page.py
python3 tools/outing_reel/make.py reel/D.json /tmp/D.mp4 0.5,4,6.5,10,14,19,22,26   # 静止画だけ
python3 tools/outing_reel/make.py reel/D.json /tmp/D.mp4                            # 動画
```

地図は国土数値情報（行政区域、dataofjapan/land の japan.geojson）から作った tools/outing_reel/paths.json。座標は x=24.0×(経度−139.65)+225、y=267.6−29.67×(緯度−35.95)。
