# 関東おでかけリストの地図（TOWN NOTES MAP）

10/29 月が作って、オーナーの「本番にして燈にバトンタッチ」で本番に入れた。ここから先は燈の物。
月の関西おでかけリストで本番になっている地図と同じ作り（見た目・動きは月と同じ。色だけ燈の都県ボタンの色）。

## 何が起きているか
- 本番のページ（/）の「おでかけ」に「地図で見る」ボタンが出る。押すと全画面の地図：関東 → 都県 → 市区町村の順に寄る。下のカードを横にめくると地図のピンが光る。
- 地図に出るのは、今のタブ（開催中・これから・もうすぐ・できた）と都県・「無料だけ」に合うカード。「もっと見る」でかくれているカードも出る。
- 試作ページ /townnotes/ も同じ物（数えない・検索に出さない）。直しを試すときに使う。

## 毎回自動でやっていること（page.yml の「地図」の段）
`scripts/townnotes.py`
1. `site/index.html` のカードの「地図」ボタンの探す言葉（= page.py の map_query・カードの `place`）で、場所を緯度経度にする。
   Nominatim → 国土地理院 → Photon の順。一度取れた場所は `data/townnotes-geo.json` に覚えて二度と調べない。取れなかった所は1日1回だけ調べなおす。
2. `site/townnotes/geo.json`（地図が読む）と試作ページを作る。
3. 本番の / に `<script src="/townnotes/map.js?v=…">` を足す（live()）。
失敗しても地図なしでページは出る。

## ピンが出ないカードがあったら
- 原因はほぼ「place が無い・あいまい」。夜の回で `place` に**施設の正式名**（例：`国営昭和記念公園`）を書けば、次の公開で自動で場所が取れる。駅名でも取れる。
- 「3か所まとめ」「お得」はピンなしでよい（1か所に決まらないため）。
- 都県（data-pref）がまちがっていると、その都県の範囲で探すので取れない（例：東京ドイツ村は千葉）。

## 地図そのものを直すとき
地図の本体は月の usagi-fudosan-media `tools/townnotes/`（関西と関東で同じ本体を使う）。
- 関東の設定（色・名物の絵の場所・都県名の位置）: `region-kanto.js`
- 燈のページとのつなぎ（タブ・都県ボタン・カードの読み方）: `site-akari.js`
- 書き出し: `python3 tools/townnotes/build_akari.py <akari-autoの場所>` → `site/townnotes/map.js` と `kanto.json`
燈のページの作り（.otab / .pane / .flt button[data-p] / .chips .fr / .card.it / .t / a.go / .when / .tg / a.mp）を変えたら、`site-akari.js` も合わせて直すこと（変えないと地図が空になる）。

## 外すとき
`scripts/townnotes.py` の最後の `live()` を消すだけ（試作 /townnotes/ は残る）。

## 押された数
燈のページでは「地図で見る」が押された数は数えていない（数えるのは買う・開くだけのまま）。
