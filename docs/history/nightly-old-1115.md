# 夜の手順から外した決まり（11/15 月）

11/14〜 関東の予定表は関西と同じ枠になり、21:00 の「HPのご紹介」の連載は出ていない（21:15 はひと駅しらべ）。台帳の指令「夜の手順が 48KB」で外した。インスタの説明文の HP 紹介1行は scripts/book.py の HP_LINES が続けて足す。

■HPのご紹介（11/2 オーナー「HPの宣伝を、今日11/2から始めて」。11/30まで毎晩読む。「人気になるまで続ける」）
- X・Threads に毎日1本。通常の枠を1つ入れ替える（本数は増やさない・PR枠は入れ替えない）。枠は 21:00（11/2 から）。data/metrics で21:00が他の通常枠の中央値を3日続けて下回ったら、別の通常枠に移して notes/strategy.md「HPのご紹介」に1行。入れ替えて出せなかったおでかけは、終わる日が先なら次の日以降に回す。
- 連載「HPのご紹介 その◯」。番号は 11/2＝その1 から月末まで続けて数える（周が変わっても1に戻さない）。7回で1周、今月いっぱい2周目・3周目とくり返す：
  ①このHPは何か（関東のくらしで見つけたことを、公式の情報つきで書きとめているノート。おでかけとおかいものの2つのリスト）
  ②何を紹介しているか（おでかけ：開催中・これから・地図／おかいもの：値下がり・くらべた物・ふるさと納税）
  ③便利な機能（地図、昼と夜の切り替え、ホーム画面に追加でアプリのように使える）
  ④/ima ⑤/tomari ⑥/nesage ⑦/furusato（1日1つ、使う場面つき）
- 形：1行目「HPのご紹介 その◯｜（その回の中身）」＋見出しの最後に絵文字1つ。1つ目の最後の行は「次回は◯◯をご紹介します。」。2つ目は「HPはこちらです（M/D時点）」＋そのページのURL（https://lifenote-kanto.pages.dev/ ・/ima ・/tomari ・/nesage ・/furusato ・/odekake ・/okaimono）。URLは2つ目だけ。2つ目には毎回、リクエストの行も入れる（11/3 オーナー「hpの紹介投稿に、リクエストのやつも書いてね！改善とか不具合ききたいし。2人とも」）：「使いにくい所・増やしてほしい物は、こちらから送れます（お名前なしで大丈夫です）」＋ https://lifenote-kanto.pages.dev/koe 。言い方は毎回少し変えてよい。
- 書くのは、そのページに今本当に出ている物だけ：書く前に WebFetch でそのページを開き、書く欄・ボタン・数字がページにあるか確かめる。見つからない機能（③の昼と夜の切り替え・ホーム画面に追加も）は書かず、ページにある別の機能に替える。件数などの数字は開いた日の数を「（M/D時点）」つきで。
- 宣伝の言葉（「ぜひ」「フォローして」「見てね」など）は使わない。HPの名前（ページの題の英字の名前など）は、オーナーが「名前が決まった」と言うまで書かない（決まったら見出しに入れる）。
- 周ごとに見出し・書き出し・具体例を変え、同じ文は出さない：書く前に notes/hp-intro.md の前の周の同じ番号の行を読み、違う場面・違う例にする。出した後に1行足す（日付｜その◯｜テーマ｜1行目｜書き出し｜具体例）。
- 予定表の形：{"slot": "21:00", "topic": "暮らし", "series": "HPのご紹介", "no": N, "x": [1つ目, 2つ目], "threads": [1つ目, 2つ目]}。
- インスタ：毎日のリール（07:30 おでかけ）の説明文の最後に、HPの紹介1行を機械（scripts/book.py の HP_LINES）が日替わりで足す。ページの機能が変わったら HP_LINES を直す。週1本のHPのリール（水曜18:00）は docs/hp-reel.md：前の夜に reel-hp/D.json を保存し、その日の reel/D.json（07:30 おでかけリール）は作らずに、そのおでかけ先を翌週に回す（1本目 11/4 は保存済み）。
- 毎晩 notes/strategy.md「HPのご紹介」に、前の日の閲覧（data/metrics の21:00）とHPに来た数（data/page-stats.json の x2100・t2100）を1行。
