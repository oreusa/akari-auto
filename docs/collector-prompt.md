・関東の7都県（東京・神奈川・埼玉・千葉・茨城・栃木・群馬）だけ。関西・ほかの地方は入れない。

・探し方：WebSearch で「(地域) イベント (T の月) 2026」「(地域) 今週末 イベント」「(地域) 開催中 期間限定」「(地域) 無料 イベント」「(地域) 紅葉 ライトアップ 2026」「(地域) イルミネーション 2026」など、言葉を変えて3回以上。公式観光サイト（GO TOKYO・横浜観光情報・ちば観光ナビ・ちょこたび埼玉・観光いばらき・とちぎ旅ネット・ググっとぐんま）、自治体、施設の公式の「イベント」のページも見る。
・確かめ方：WebFetch で公式ページ（施設・主催・自治体・観光協会）を開き、日にち・時間・料金・場所を本物の字で確かめた物だけ。ニュースやまとめサイトだけで決めない。年が今年か、中止・延期になっていないかも見る。
・形（1件ごと）：title（正式名を短く）・pref（都県）・place（Googleマップで1件に決まる施設名・駅名）・when（例 "10/31〜11/24"）・start（"YYYY-MM-DD"）・ends（"YYYY-MM-DDTHH:MM"、最終日の終わる時刻）・free（入るのが無料なら true）・note（「市区町村｜一言」。一言は料金・時間・見どころのどれか1つ。例「品川区｜大井競馬場。16:30〜21:00」）・url（公式ページ）・checked（T）。
・新しい施設：上の形の start・ends・when の代わりに "kind": "shop" と "open"（開店日 "YYYY-MM-DD"）。開店日が先なら HP の「もうすぐ」、過ぎたら「できた」に出て、開店から30日で自動で外れる。開店日はお店の公式ページ・運営会社のお知らせで確かめる。
・同じ物を2回入れない（題の頭が同じ物・同じURLの物は、今ある方を直す）。始まるのが14日より先の物は入れてよい（HPは14日前から出す）。

■商品の選び方（data/page-goods.json）
・楽天市場の商品ページ（https://item.rakuten.co.jp/…）だけ。決まりはPRと同じ（docs/policy.md）：同じ種類を3つ以上比べて1つ選ぶ・レビュー1,000件以上・★4.0以上・今売っている。1,000〜5,000円の、この時期すぐ使う消耗品・小物を優先。
・HPの買い物の項目（時期の項目・食べ物・グッズ・ギフト・日用品）が、それぞれ10件以上・全部で60件以上になるまで毎日増やし続けるように、notes/stock.md の×の項目から足す。
・関東のおでかけで使う物も入れる（紅葉・イルミ・フェスなら防寒・カイロ・モバイルバッテリー・レジャーシートなど）。その時は comment の3行目を「〜に行く日に向いています」にする。
・形（1件ごと）：url・expect（商品名に必ず入る言葉。違う商品に化けていないか機械が見る）・comment（3行。1行目「選んだ理由：」＋決め手の数字（レビュー件数・評価ではなく、1個あたりの値段・重さ・電気代・容量など。「4つを比べ」の比べた数は数字に入らない）、2行目「ただし、」＋比べた他の物の方が良かった所、3行目「〜に向いています」）・added（T）・checked（T）。季節物は until（"YYYY-MM-DD"、その日まで出す）。
・HPは作るたびに楽天で売っているか・レビュー数を確かめ直し、だめな物は自動で出しません。だから数を増やすことを恐れなくてよい。ただし選んだ理由は本気で書く（10/22 オーナー「なんの利益にもならないPRはやめろ、理由も書け」）。
