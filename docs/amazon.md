# Amazonを極める（10/23 オーナー「Amazon推しだから、何とかAmazonを極めて欲しい」）

夜の回が毎晩読む。Amazonの売上とクリックはオーナーだけが見る。燈は「出した本数」と「Xで押された回数」で学ぶ。

## 1. 毎日1本は必ず出す
- 18:15の比較PRはAmazonにする。「Amazon確認帳」に条件（レビュー1,000件以上・★4.0以上）を満たす○が無い日だけ楽天にし、理由を最後の1行に書く。
- 22:15のPRは、楽天に条件を満たす物が無く、確認帳に別の種類の○があればAmazonにしてよい（1日のPRは4本までのまま）。

## 2. 何を選ぶか（売れやすい順）
- 柱（notes/strategy.md）に合わせ、その日のおでかけの場面で使う物（防寒・持ち物）だけ。商品そのものを主役にした話にしない。
1. すぐ使う消耗品・小物で、税込1,000〜5,000円。例：カイロ、加湿器のフィルター、保湿クリーム、電池、ケーブル、モバイルバッテリー、マスク、食品の箱買い。
2. その日の投稿の場面とつながる物（おでかけ→携帯カイロ、温泉→タオル、冬支度→すき間テープ）。
3. Amazonが強い物：まとめ買い・定期おトク便がある日用品、Amazonブランド、レビューが数万件ある定番。
- 比べ方の数字：1個あたり・1回あたり・1日あたりの値段、レビュー件数×★。見出しは「【AIが比べた○○ 3つ】」に結果の数字を入れる。

## 3. 学び（毎晩1行、notes/amazon-learning.md）
- 形：`Y｜枠｜種類｜税込価格｜Xクリック｜見出しの最初の15字`
- 5行たまったら、クリックの多かった値段帯と種類を次の18:15に優先する。0クリックが3日続いた種類はやめる。
- オーナーが「売れた」と言った種類は、いちばん上に「★売れた：種類（日付）」と書き、同じ種類を週2回まで出す。

## 4. 大きな売り時
- Amazonブラックフライデー（11月下旬ごろ）とプライム感謝祭などの大きなセールは、日程が出たら schedule の前の週から18:15と22:15をAmazonにし、「セールで1個あたり○円」の比べ方にする。
- タイムセールの値段は変わりやすいので、文には確認帳の値段と「（10/23 20:20時点）」の形の時刻を書く。

## 5. やらないこと
- 確認帳にない物、凪が開いていない物は出さない（機械が×にする）。
- amazon.co.jp のURLを本文に直書きしない（機械が tag 付きで入れる）。
- 「いちばん安い」「絶対」など確かめられない言葉は使わない。
