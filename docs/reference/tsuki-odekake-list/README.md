# 月の「関西おでかけリスト」（参考用コピー）

オーナーの依頼（2026-10-26）で、月のサイトを燈のアフィリエイトHPの参考として置いています。
燈の作業環境からは月のサイト（workers.dev）を開けないため、2026-10-26 時点のファイルをそのままコピーしました。
このフォルダは見るためだけのものです。燈のサイトには組み込まれていません。

- `index.html`：おでかけリスト本体（CSS と JS はすべてこの1ファイルの中）
- `gyosha.html`：業者さま向けの小さなページ
- `assets/logo.png`：ロゴ（フォントは重いのでコピーしていません。字は Shippori Mincho・Zen Kaku Gothic New・Jost）
- `screenshot-phone.png`：スマホ幅（400px）で撮った全体

## オーナーが気に入っている点・決めたこと
- シンプルでお洒落。色は「意味のあるところだけ」（府県の見分け）。無理にカラフルにしない（10/26「目がチカチカ」で戻した）。
- 見出しは明朝（Shippori Mincho）＋小さな英字ラベル（NOW ON / COMING UP など、字間広め、茶色）。
- 4つの欄（開催中・これから・もうすぐ・できた）は1つの箱にまとめてタブで切り替え。タブの下に小さく「7件」。
- 各欄は最大5件、残りは「もっと見る（あと◯件）」。ページを下に長くしない。
- カードは低く：1行目に府県・日付、2行目に名前、右上に矢印、右下に「地図」。住所の行は出さない。
- 下の部分：フォローは下線の文字を1列。相談の3つは1つずつ白い箱（細い線の枠、色なし）。オーナー「線だけだと間違って押しそう」で白い箱に。
- 業者さま向けページ（gyosha.html）も同じ形に統一（screenshot-gyosha.png）。
- オーナーが嫌がったもの：動き（アニメーション）、ぼかし、大きな番号、タグだらけ、文字が多い、縦長のカード、濃い黒ボタン（「重圧感」）。
