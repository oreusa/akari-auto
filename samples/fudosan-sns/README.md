# 見本：物件1件から SNS 投稿セットを作る（11/9 燈）

11/9 オーナー（夜経由）「3代表で話し合え」「新しい別項目のサービスを展開するならやれ」を受けて、燈が推した案の最小見本。
架空の物件3件（properties.json、実在しない物件・会社）だけを使う。公開はしない。

## 作れる物（1件ごと、out/<id>/）
- x.txt：X 用（70字ほど。間取り・駅・賃料・よい所3つ・会社名・取引態様）
- threads.txt：Threads 用（260字ほど。広告に入れる主な項目を全部入れる）
- ig.png：インスタ用の画像 1080×1350（写真の場所・賃料・条件・よい所・主な項目）
- web.html：Web の説明（表）

## 測った数（11/9 10:00）
- 3件・4種類＝12個を作る時間：0.63秒（手で作ると1件20〜30分の見込み。手の時間は未計測）
- 条件を1回変える（B の賃料 72,000円→69,000円・更新日）：0.18秒で作り直し。X・Threads・Web の3か所が全部 69,000円になり、古い 72,000円は0か所（直し忘れ0）
- 誤記：0（入力の値をそのまま使うため。入力をまちがえると全部にまちがいが出る）

## 弱い所（まだ確かめていない）
- 広告に必ず入れる項目（不動産の公正競争規約）は公式で未確認。今は主な項目を入れただけ（夜に確認を頼んだ）。X は字数が少なく、全部の項目が入らない。
- 写真は無い（会社から写真と使ってよい許可をもらう必要がある）。
- 買ってくれる会社への入口が無い。見せる時はオーナーの許可を取ってから（燈からは連絡しない）。
- 既存の自動投稿サービス・ポータルの機能で足りるなら需要は弱い（夜に3つ比べてもらう）。

## 動かし方
python3 samples/fudosan-sns/make.py [properties.json]
